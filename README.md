# Картки для PocketBook

Флеш-картки в стилі Quizlet для PocketBook InkPad Color (741) та інших моделей на платформі B288 (InkPad 3, Touch HD 3 тощо). Нативний застосунок на InkView, root не потрібен.

## Встановлення

1. Підключіть книжку до комп'ютера кабелем.
2. Скопіюйте вміст архіву в корінь пам'яті книжки:
   - `applications/Flashcards.app` у папку `applications`;
   - папку `flashcards` з прикладом колоди — у корінь.
3. Відключіть кабель і відкрийте **Програми → Flashcards**.

Під час першого запуску застосунок сам створить папку `flashcards` і колоду-приклад `english-basics` (40 фразових дієслів і слів рівня B1–B2), якщо їх ще немає.

## Свої колоди

Кожна колода — це текстовий файл `.tsv` (або `.txt`) у папці `flashcards` у пам'яті книжки або на SD-карті. Назва файлу стає назвою колоди, а `_` замінюється на пробіл.

Формат такий самий, як експорт з Quizlet: одна картка в рядку, між колонками — табуляція.

```
слово<TAB>переклад<TAB>приклад (необов'язково)
reliable	надійний	Our backups are reliable.
```

- Рядки, що починаються з `#`, вважаються коментарями.
- Якщо в рядку немає табуляції, роздільником може бути `;` або ` - `.
- `\n` у перекладі або прикладі стає переносом рядка.

**Як експортувати з Quizlet** (якщо для набору доступний експорт): відкрийте набір, натисніть **⋯ → Експорт**. Між терміном і визначенням оберіть «Табуляція», між рядками — «Новий рядок». Скопіюйте текст і збережіть його у файл `назва.tsv` в кодуванні UTF-8.

## Як вчитися

- Торкніться картки або натисніть кнопку гортання, щоб перевернути її.
- Потім оберіть **Знаю** чи **Не знаю**. Фізичні кнопки працюють так: «назад» означає «не знаю», «вперед» — «знаю».
- Картка, на яку ви відповіли «не знаю», повернеться через кілька карток у цій самій сесії.
- **Меню** дозволяє змінити напрям (слово → переклад або навпаки), кількість нових слів за сесію (10/20/30/50/усі), перемішування, а також скинути прогрес колоди.

### Інтервальне повторення

Застосунок використовує систему Лейтнера з шістьма рівнями. Коли ви відповідаєте «знаю» з першої спроби, картка піднімається на рівень вище, і наступного разу ви побачите її через 1, 2, 4, 8, 16 або 32 дні. Після помилки картка повертається на перший рівень. Новий день починається о 03:00, тож заняття пізно ввечері зараховуються на поточний день.

Кожна сесія спершу показує картки, які сьогодні треба повторити, а потім нові слова в межах ліміту. Кнопка **Повторити всі картки** запускає зубріння всієї колоди. Цей режим не змінює рівнів правильних відповідей.

Прогрес зберігається після кожної відповіді у файлі `flashcards/.progress/<файл>.progress`. Він прив'язаний до тексту слова, тому колоду можна доповнювати й переставляти рядки, не втрачаючи прогресу.

## Збірка з вихідних кодів

Потрібен Linux x86-64. На macOS чи Windows скористайтеся `Dockerfile`.

```sh
# лише тека SDK-B288 з гілки 6.5 (~2 ГБ)
git clone --depth 1 --branch 6.5 --filter=blob:none --sparse \
    https://github.com/pocketbook/SDK_6.3.0 sdk
git -C sdk sparse-checkout set SDK-B288

make            # build/Flashcards.app (ARM, softfp)
make test       # юніт-тести логіки на хості (з ASan/UBSan)
make preview    # PNG-знімки екранів через мок InkView (потрібні libfreetype і libpng)
make package    # build/Flashcards-PocketBook.zip
```

Структура проєкту:

- `src/deck.c` — колоди, прогрес і планувальник повторень. Це чистий C без InkView, тому його легко тестувати.
- `src/main.c` — інтерфейс на InkView: екрани, кнопки, меню.
- `mock/mock_inkview.c` — хостова заглушка InkView на FreeType. Вона малює екрани в PNG за сценарієм подій.
